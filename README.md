# 🌸 LepestOk — Сайт цветочного магазина

**LepestOk** — это современный, адаптивный одностраничный сайт (landing page) для цветочного магазина. Проект создан с акцентом на визуальную эстетику, плавные анимации и удобство пользователя, чтобы передать атмосферу нежности и заботы, которую дарят цветы.

## ✨ Особенности и функционал

- 🌺 **Анимация падающих лепестков**: Уникальный эффект на чистом JavaScript, создающий волшебную атмосферу на фоне сайта.
- 📱  **Полная адаптивность**: Корректное отображение на всех устройствах (десктопы, планшеты, смартфоны).
- 🎨 **Современный UI/UX**: Использование градиентов, мягких теней, эффектов при наведении (hover) и стеклянного морфизма (backdrop-filter).
- 📜 **Плавная прокрутка**: Навигация по якорным ссылкам с плавным скроллом к нужной секции.
- 👁️ **Анимация при скролле**: Элементы плавно появляются (fade-in) при прокрутке страницы с помощью `Intersection Observer`.
- 📬 **Форма обратной связи**: Готовая форма с базовой валидацией и интерактивным уведомлением об успешной отправке.

## 🛠️ Технологический стек

Проект разработан на классическом стеке веб-технологий без использования тяжелых фреймворков, что обеспечивает высокую скорость загрузки:

- **HTML5** — семантическая разметка.
- **CSS3** — стилизация, Flexbox, CSS Grid, ключевые кадры анимации (`@keyframes`), медиа-запросы.
- **JavaScript (Vanilla)** — логика анимации лепестков, отслеживание скролла и обработка формы.

```text
  LepestOk/
```

## 🚀 Установка и запуск

Проект не требует сборки или установки зависимостей (npm, Node.js и т.д.). Чтобы запустить его локально:
  1. Клонируйте репозиторий или скачайте его в виде ZIP-архива
  2. Перейдите в папку проекта
  3. Откройте файл index.html в любом современном браузере (двойным кликом или через Live Server в VS Code).
   
⚠️ Примечание: Для корректного отображения изображений и иконок требуется подключение к интернету, так как они загружаются с внешних ресурсов (Pinterest, Icons8).

## 📄 Секции сайта

1. Главная (Hero): Приветственный экран с призывом к действию.
2. Услуги: 8 карточек с описанием услуг (букеты на заказ, свадебная флористика, подписка на цветы и т.д.) и ценами.
3. Почему мы: 6 ключевых преимуществ магазина.
4. О нас: Краткая история команды и миссия.
5. Отзывы: Блок с отзывами довольных клиентов.
6. Контакты: Контактная информация (телефон, email, адрес в Ярославле, часы работы) и форма для заявки.
7. Футер: Ссылки на социальные сети и копирайт.
